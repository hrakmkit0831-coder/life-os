# LIFE OS

自分との約束を守るための、iPhone 向け個人用「指令室」PWA。
**目標を立てるより実行する／失敗を記録するだけでなく次の行動を変える** が中心原則。

- データはすべて端末内（IndexedDB）。外部送信・解析サービス・外部 AI なし
- オフライン動作（Service Worker）、ホーム画面に追加して全画面で使用可

## 画面

| 画面 | 内容 |
|---|---|
| ホーム | 次にやること（5分だけ始める／集中）、最重要タスクのその場決定、重要タスク最大3件、習慣、進捗、振り返り導線、未完了の仕分け・立て直しの提案 |
| 実行 | タスクの追加・編集・削除・完了・延期・分割、期限切れ表示、集中の記録 |
| 集中タイマー | 5/15/25/45/60分・任意。一時停止/再開。開始時刻と終了予定時刻を保存し再計算 |
| 生活 | リズム（睡眠・目標）／健康（運動・食事・体調）／時間（勉強・仕事・SNS/ゲーム手入力）／お金（支出・日週月合計・カテゴリ別） |
| 振り返り | 事実（計画 vs 実績）、最重要の完了、できた/できなかった、原因（選択式）、未完了の仕分け、明日の改善1つ |
| 分析 | 7日/30日。完了率（分母明記）、習慣率、睡眠・勉強仕事・スマホ・支出の推移、原因ランキング、根拠つきの傾向（少数は「仮説」） |
| 朝のチェックイン | エネルギー・使える時間・最重要・重要（最大3）・やらないこと → ルールベースで計画提案 |
| 立て直し | 未完了を全部仕分け → 今日の1つ → 5分の行動 → 開始 → 次の小さな行動 |
| 設定 | Strict Mode、日の切り替え時刻、習慣管理、JSON 書き出し/読み込み、全削除 |

## 起動

```bash
# Node.js はポータブル版を ~/tools/node に配置済み（PATH に追加して使う）
export PATH="$HOME/tools/node:$PATH"     # PowerShell: $env:Path = "$HOME\tools\node;" + $env:Path

npm install
npm run dev        # 開発サーバー http://localhost:5173
npm run build      # dist/ に本番ビルド
npm run preview    # 本番ビルドを http://localhost:4173 で確認（Service Worker 有効）
```

## テスト

```bash
npm run typecheck  # 型チェック
npm test           # ユニットテスト（Vitest + fake-indexeddb）
npm run e2e        # E2E（Playwright: iPhone 13 / iPhone SE 相当の WebKit、オフラインは Chromium）
# 初回のみ: npx playwright install webkit chromium
```

## iPhone での確認

1. PC と iPhone を同じ Wi-Fi に接続
2. `npm run build && npm run preview` → 表示される `Network: http://192.168.x.x:4173` を iPhone の Safari で開く
3. この方法（http）では **Service Worker が動かないためオフライン機能は無効**。データ保存・操作・レイアウトの確認はできる

オフラインまで含めて使うには **HTTPS で配信** する必要がある。`dist/` を静的ホスティング（GitHub Pages / Cloudflare Pages / Netlify など）に置けばよい。配信されるのはアプリのプログラムだけで、記録データは各端末の中に留まる。

## ホーム画面に追加（Safari）

1. Safari で LIFE OS を開く
2. 画面下の共有ボタン（□↑）→「ホーム画面に追加」
3. 名前が「LIFE OS」になっていることを確認して「追加」
4. ホーム画面のアイコンから起動すると全画面表示になる

注意: Safari で開いたときとホーム画面から開いたときは **保存領域が別** になる。使い始める場所をどちらかに決める（推奨: ホーム画面）。移行は JSON の書き出し→読み込みで行う。

## データの保存とバックアップ

- 保存先: ブラウザの IndexedDB（データベース名 `life-os`）。ストア: tasks / habits / habitLogs / checkins / reviews / focusSessions / sleepRecords / exerciseRecords / healthRecords / timeRecords / screenTimeRecords / expenseRecords / settings
- 起動時に `navigator.storage.persist()` を要求し、自動削除されにくくしている
- 書き込みはトランザクション単位。失敗時は画面を変更せずエラー表示
- バックアップ: 設定 →「JSON で書き出す」→ ファイルアプリで iCloud Drive などに保存。14日以上書き出していないとホームに表示
- 復元: 設定 →「JSON を読み込む」→ 形式検証 → 件数確認 → 置き換え確認
- 削除: 設定 →「すべてのデータを削除」（確認＋「削除」入力）

### 記録の更新ルール

| 種類 | ルール |
|---|---|
| チェックイン・振り返り・睡眠・運動・食事体調・勉強仕事・スクリーンタイム | 1日1件。同じ日に再入力すると上書き（作成日時は保持） |
| 習慣 | 1習慣×1日 = 1件（タップで切り替え） |
| 支出・集中セッション | 追記型（何件でも） |
| タスク削除 | 論理削除（分析の分母を正しく保つため）。全削除で完全消去 |

- 日付は「論理日付」。既定では朝4時に日付が切り替わる（深夜2時の作業は前日扱い）。設定で 0〜5時に変更可
- 睡眠は起床した日に記録。就寝時刻が起床時刻より後なら前日に寝たとして計算
- スキーマ変更時は `src/lib/db.ts` の `MIGRATIONS` に追記する（既存ストアは削除しない）

## 既知の制約（Web アプリの限界）

- スクリーンタイム／アプリ使用時間は自動取得できない → 手入力
- アプリを閉じている間のタイマー終了通知は出せない（開いているときは画面表示と音）
- 端末間の自動同期なし（JSON で移行）
- http（LAN）配信ではオフライン不可。HTTPS 配信が必要
